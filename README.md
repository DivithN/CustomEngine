# Custom C++ Game Engine / Treasure Hunt

A custom 3D game engine and treasure-hunt game developed primarily in C++,
with lightweight Lua scripting support.

## Gameplay
https://www.youtube.com/watch?v=Jpw_dVeAsWc

## Key Systems

- Custom C++ engine architecture
- Transform/keyframe animation system
- Maya animation export pipeline
- Spatial audio integration
- Graphics/rendering systems
- Asset management
- Physics
- Input
- Game object architecture
- Lua scripting integration

## My Work

I implemented the animation system used by Treasure Hunt, including
transform-based keyframe playback, looping, gameplay events, and the
pipeline for exporting animation data from Maya.

I also integrated spatial audio into the engine and built the gameplay-side
audio pipeline used by the game.
